# Gustavo Prado — Portfolio

Portfolio em React, TypeScript e Vite, com styled-components, componentes no
padrão shadcn/ui, Motion, Lucide e ShaderGradient.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

Os dados profissionais, projetos e links são baseados no currículo de Gustavo
Prado. Para atualizar conteúdo e links, edite os dados no início de
`src/App.tsx`.

A foto da abertura fica em `public/gustavo-prado.jpeg`.
